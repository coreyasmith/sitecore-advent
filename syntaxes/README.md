# Syntaxes

TextMate grammars for code block languages that [Shiki][shiki-langs] doesn't bundle. `astro.config.mjs` registers them in `markdown.shikiConfig.langs`.

- `plantuml.tmLanguage.json` is from [qjebbs/vscode-plantuml@7bc1758][plantuml-src], converted from YAML to JSON. It's licensed under MIT; see [plantuml.LICENSE.txt](plantuml.LICENSE.txt).
- `structurizr.tmLanguage.json` is from [ciarant/vscode-structurizr@00e2132][structurizr-src], unmodified. It's licensed under MIT; see [structurizr.LICENSE.txt](structurizr.LICENSE.txt).
